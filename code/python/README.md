# Python eBPF Examples

This folder contains example Python scripts that use BCC to compile and attach eBPF programs in the Linux kernel.

## Files

- `chmod.py`
  - Watches for file permission changes on a target file (`test.txt`).
  - Attaches a kprobe to `security_path_chmod` and prints a message when the target file is modified.

- `delete_file.py`
  - Detects deletion of a target file (`test.txt`).
  - Uses a kprobe on `security_inode_unlink` to watch kernel unlink events and reports when the target file is removed.

- `exec.py`
  - Demonstrates a simple eBPF tracepoint attached to the `execve` syscall.
  - Prints a "Hello World" message from the kernel each time a process executes a new program.

- `ping.py`
  - Tracks all outgoing network packets generated by the `ping` process.
  - Hooks `__dev_queue_xmit` and filters on the `ping` command name.

- `write_file.py`
  - Detects writes to a target file (`test.txt`).
  - Attaches a kprobe to `vfs_write` and prints when the target file is written.

## Notes

- These scripts require Linux and the BCC Python bindings.
- Run them with root privileges, for example:
  ```bash
  sudo python3 chmod.py
  ```

- Adjust `TARGET_FILE` in `chmod.py`, `delete_file.py`, and `write_file.py` if you want to monitor a different filename.

## What is a kprobe?

A kprobe is a kernel probe that lets eBPF attach to a kernel function entry point. When the target kernel function is called, the kprobe runs the attached eBPF program so you can trace events, inspect arguments, or gather data without modifying the kernel source.
